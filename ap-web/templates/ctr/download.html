Testing channel

Hosting or generating?

Players joining somebody else's multiworld only need the client above. If you are generating the multiworld yourself, you also need the CTR APWorld for your Archipelago install. A documented template YAML is published as a separate release asset. The easier option is to build a compatible YAML in the guided Builder.

  • Download the CTR APWorld ({{ stable.version }})
  • Download the template YAML ({{ stable.version }})
  • Build a {{ stable.version }} YAML in your browser

Other platforms
