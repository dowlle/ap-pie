## 10 September 2026

### CTR Archipelago 0.2.0

The release notes now lead with the main features and three starting paths: joining, preparing a YAML or hosting. Upgrade advice and the Steam Deck fullscreen workaround are easier to find. The Builder now exposes all 52 CTR options, including Racer-Locked Warp Pads from 0 to 27, with the character settings grouped together.

CTR 0.2.0 is now the stable download for Windows, Linux and Steam Deck, with the matching APWorld and YAML template. The [full release notes](/ctr/reference/0-2-0-release-notes), [setup guide](/guides/ctr) and [reference pages](/ctr/reference) explain the new options, twenty traps, experimental recorded AI and remaining community testing.

Use the [0.2.0 YAML Builder](/yaml-builder/ctr?version=0.2.0) for new games. The setup and hosting guides link to Appie's YouTube walkthroughs; a dedicated CTR 0.2.0 YAML explanation video is coming soon.

## 8 September 2026

### YAML Builder fixes

- **Rayman 2:** exported YAMLs now use the APWorld's registered game name, fixing the “No world found” error.
- **Hades and other APWorlds:** the Builder no longer treats an index release label as a generator-recognized world version. This fixes unsupported version requirements in exported YAMLs.
- **More games supported:** improved option parsing for games including LEGO Star Wars: The Complete Saga, and refreshed previously failed schema results.
- **Readable number fields:** long counter labels, including Refunct's minigames, now fit beside their values at desktop and mobile widths.

Fresh Rayman 2 and Hades default exports passed five generation seeds each, plus three seeds with both games together, on Archipelago 0.6.7. This checks generation, not in-game play or every settings combination. If you downloaded an affected YAML earlier, create a fresh copy in the [YAML Builder](/yaml-builder).

### Favorites and room joining

- Save personal favorite games with the star beside Download, and find them under **My → Favorite games**.
- Join an open collection room before uploading a YAML, then select it as a destination from the Builder.
- Catalog actions now include hover and keyboard-focus help.

### Guides and site updates

- Click a fuzz-result badge to see its recorded result and an explanation. The new [fuzzer guide](/guides/what-is-the-fuzzer) explains clean, flaky and broken results.
- The [hosting guide](/guides/hosting-a-multiworld) includes a video walkthrough alongside the written steps.
- Site footers now link to the changelog, issue reporting and Dowlle's Ko-fi page.

This changelog starts with the September 2026 updates. Earlier releases are not listed here yet.
