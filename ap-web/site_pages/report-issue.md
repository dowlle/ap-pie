Something wrong with the YAML Builder, collection rooms, favorite games or another part of AP-Pie? Send a report so it can be reproduced and investigated.

<p><a class="btn btn-primary" href="https://github.com/dowlle/ap-pie/issues/new?template=bug_report.yml">Report an AP-Pie issue on GitHub</a></p>

A GitHub account is required to submit the form. You can [browse existing reports](https://github.com/dowlle/ap-pie/issues) without signing in. Check the [changelog](/changelog) too, as your problem may already have a fix.

## What to include

- What you were trying to do and the steps that led to the problem.
- What you expected, what happened instead, and the exact error message.
- For Builder or generation problems: the game, APWorld version, Archipelago version and whether you changed the default settings.
- Your browser and device, plus a screenshot or a small example if it helps.

GitHub reports are public. Remove private room links, player details, tokens and other personal information before sharing screenshots, logs or YAMLs. Do not include passwords. This page does not upload anything; you review and submit your report on GitHub.

## A game or APWorld problem?

If the game itself, its client or its randomizer is failing, start with the support links on that game's [APWorld catalog entry](/apworlds). Include the exact version and error when contacting the project's support space.

If an AP-Pie-generated YAML fails while the game's own template works, report it here as a Builder issue. If you are unsure where the problem starts, describe what you tried in the AP-Pie report.

## Private account or security concerns

Contact Appie (Dowlle) on Discord for private account or security concerns, rather than posting sensitive details publicly. See the [privacy page](/privacy) for account and data requests.
